# YogurtLib Auton Sim

A browser simulator for testing YogurtLib autonomous routines off the robot, and also a playground to test YogurtLib's Monte Carlo Localization (MCL). A virtual simulator can have a robot's true pose, so localization can be compared against a ground truth.

## Run it

Open `index.html` in a browser. There is no need to build or install anything.

## Conventions

Same as YogurtLib: 
- Distance: inches
- Field Convention: w/ field center at (0, 0), starting from -72 to 72 on both axes(inside walls are realistically around ~70.2in), math heading (north = 90°, east = 0°, CCW positive).

## How this was built

My only JavaScript experience before was a Grade 10 programming class, so I used Claude as a tutor to help:

- **Planning:** Claude helped plan the architecture with me and the order to build things in.
- **Starter scaffold:** the starting parts were generated by Claude -- the page layout (`index.html`, `style.css`), the animation loop, the side panel, and empty function stubs.
- **Everything after is mine**: the code logic to draw, coordinate transform, field and robot drawing, motions, command runner, and later the simulation and MCL logic.
- **Tutoring:** I ask Claude to explain JavaScript syntax and canvas drawing when I don't understand them, and to check my logic after I've written it. The commit history shows where my code starts.

## Roadmap

1. Kinematic sim: the robot runs a list of commands named after the real `Drivetrain` functions.
2. Drive model: left/right voltages to wheel speeds to pose, with noise so the believed pose drifts from the true pose.
3. Run the real YogurtLib C++ motions against a simulated robot and replay the result here.
4. MCL: simulated distance sensors and a particle filter.
